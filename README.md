# Image Prompt Analyzer

**Image Prompt Analyzer** 是一个用于反向拆解图片和图片生成提示词的 Manus Skill。它把视觉画面整理成结构化、可执行、可复用的提示词规格，重点回答以下问题：

1. 主体是谁或是什么？
2. 主体位于画面什么位置？
3. 画面采用什么构图和视觉动线？
4. 背景使用什么环境、颜色与空间层次？
5. 主体和环境呈现什么材质？
6. 灯光从哪一侧来，阴影如何分布？
7. 镜头距离、景别和视角是什么？
8. 文案应留在哪里，安全区有多大？
9. 哪些元素必须固定，哪些元素允许替换？

该 Skill 适合参考图分析、图片生成提示词重写、图片编辑说明、系列化视觉模板和儿童绘本/海报/广告等画面的风格拆解。

## 功能概览

### 反向拆解参考图

从图片中提取主体、位置、构图、层次、背景、材质、光线、镜头和留白。对不确定内容区分“直接观察”“合理推断”和“无法确认”，降低凭空编造细节的风险。

### 重写图片生成提示词

将自然语言需求或已有提示词改写成结构清晰的生成提示词，按照“主体与动作 → 位置与比例 → 构图与动线 → 背景 → 材质 → 灯光 → 镜头 → 风格 → 文案留白 → 限制条件”的顺序组织。

### 提炼系列视觉模板

把画面拆成**固定项**和**可替换项**。固定项用于保持同一系列的视觉一致性；可替换项用于生成不同人物、产品、季节、道具或场景的变体。

### 生成编辑指令

根据分析结果输出图片编辑说明，例如“保留主体位置和光线方向，只替换背景与服装颜色”，适合局部重绘、扩图、换背景或系列化改稿。

### 规划文案留白

在生成画面前明确标题、品牌名、说明文字或按钮的预留区域，描述位置、面积、背景干扰和安全距离。真实文字建议后期排版，不依赖图像模型直接生成准确字形。

## 如何使用

直接在 Manus 中提供以下任一类型的输入即可：

### 分析参考图

> 请分析这张参考图，重点说明主体位置、构图、背景、材质、灯光方向、镜头距离和文案留白，并区分固定项与可替换项。

### 拆解已有提示词

> 请拆解下面这条图片提示词：……。按照主体、位置、构图、背景、材质、灯光、镜头、文案留白、固定项和可替换项输出。

### 重写生成提示词

> 请将这段需求改写成可直接用于图片生成的提示词：……。保持主体在右侧三分之一，左侧预留标题空间。

### 生成系列模板

> 请以这张图为基准，提炼一套系列化视觉规范。固定画幅、构图、光线和文案区，只允许替换人物、道具和背景场景。

### 生成图片编辑指令

> 保留参考图中主体的姿态、位置、光线和构图，只将背景替换为春天的花园，并保持右上方文案留白不变。

## 推荐输入信息

输入越具体，分析越稳定。建议尽量提供：

| 信息 | 示例 |
|---|---|
| 图片或参考图 | 上传图片、截图或提供已有提示词 |
| 用途 | 绘本单页、广告海报、商品主图、社交媒体配图 |
| 画幅 | 4:5 竖版、16:9 横版、1:1 方形 |
| 主体要求 | 人物、产品、动物、数量、动作和年龄感 |
| 风格要求 | 水彩、彩铅、版画、摄影、三维渲染、复古印刷 |
| 文案要求 | 标题区域、品牌名位置、预计文字长度 |
| 固定要求 | 必须保留的颜色、姿态、Logo、构图和光线 |
| 可变要求 | 可替换的人物、背景、季节、道具或材质 |

如果缺少参考图，Skill 会基于文字进行合理推断，但会在“置信度/依据”和“待确认项”中标明推断内容。

## 标准输出结构

默认输出包含以下部分：

1. **一句话视觉摘要**：概括主体、构图、风格和用途。
2. **画面结构表**：按维度记录画幅、主体、位置、构图、背景、材质、灯光、镜头、文案留白与风格，并标注置信度或依据。
3. **固定项**：列出系列一致性必须保持的内容。
4. **可替换项**：列出可变内容、允许范围以及替换后不能破坏的约束。
5. **可直接使用的提示词**：提供生成版，必要时额外提供编辑版。
6. **风险与待确认项**：说明参考图不可见信息、推断项、尺寸问题和文字生成限制。

## 字段说明与判断标准

### 主体

描述主体类别、数量、主次、动作、姿态、关键轮廓和视觉焦点。不要在画面不可见处擅自补充人物身份、年龄、品牌型号或产品功能。

### 位置

使用左/中/右、上/中/下、前景/中景/背景等相对位置。必要时说明主体与画面边缘、文案区和其他元素的距离关系。

### 构图

不能只写“黄金分割”或“对称构图”，还应说明视觉动线、元素大小层级、裁切方式、负空间和景深。优先使用可执行表达，例如“主体位于右侧三分之一，左侧保留连续浅色平面”。

### 背景

说明背景是纯色、渐变、摄影环境、抽象纹理还是具体场景，并说明背景是否需要弱化、虚化或服务于主体轮廓分离。

### 材质

写出表面线索，例如金属反射、玻璃折射、纸张颗粒、织物褶皱、木材纹理或液体高光，而不是只使用“高级质感”一类不可执行的形容词。

### 灯光

说明主光的左右、上下、前后方向，光质、色温、阴影方向、高光位置和轮廓光。若不能确认，应标注为“疑似”或“生成约束”，不要将推断写成观察事实。

### 镜头

优先描述景别、视角、透视强弱、背景压缩和景深；只有有足够证据时才给出具体焦段。没有必要为了显得专业而强行写出 35mm、50mm 等数字。

### 文案留白

说明文案位于哪个区域、占多少空间、是否连续干净、与主体保持多远、背景对比度是否足够，以及是否需要渐变遮罩。文字内容本身应由用户提供或后期添加。

## 使用示例

### 示例需求

> 分析一张竖版儿童绘本插画：两个约 1 岁的幼儿坐在客厅地毯上一起看绘本。请拆解画面，并告诉我哪些内容固定、哪些内容可以替换，最后给一条可直接生成类似画面的提示词。画面上方要留标题位置。

### 期望分析摘要

- **主体**：两个约 1 岁的幼儿，共同翻看一本打开的大图画书。
- **位置**：两个幼儿位于画面中央偏下，书本位于前景中央。
- **构图**：书页与两张脸形成稳定三角关系，视线从书页移动到人物表情。
- **背景**：温暖客厅、柔软地毯和简化的低矮书架，背景不抢主体。
- **材质**：纸张、织物和木质家具，整体哑光并带有纸张颗粒。
- **灯光**：柔和窗光从左上方进入，接触阴影轻柔。
- **镜头**：中近景、平视或略低机位，人物清晰，背景适度虚化。
- **文案留白**：画面上方约四分之一保留连续浅色区域，用于后期添加标题。

### 固定项示例

两个幼儿的年龄感和共同阅读关系、竖版画幅、主体位于中下部、书本位于前景中央、上方标题安全区、经典水彩与彩铅绘本风、柔和自然光、无文字无水印。

### 可替换项示例

服装颜色、发型、绘本封面图案、地毯颜色、客厅小道具、窗外季节和辅助色。替换时保持两个孩子的年龄比例、面部可见度、书本位置和标题留白不变。

### 生成提示词示例

> 两个约 1 岁的幼儿坐在温暖客厅的柔软地毯上共同阅读一本打开的大图画书，两个孩子是画面主要视觉焦点，位于画面中央偏下，书本位于前景中央，形成书页与两张脸的稳定三角构图；一个幼儿用手指向书页，另一个幼儿靠近观看，动作自然、符合幼儿年龄；背景为简洁的低矮木质书架、少量布艺玩具和柔和室内空间，背景细节弱化；柔和自然窗光从左上方照入，阴影轻柔，人物边缘有淡淡轮廓光；中近景、平视视角、轻微浅景深；经典儿童读物插画风，手绘水彩与彩铅结合，低饱和暖色，柔和纸张纹理，圆润友好的造型；画面上方保留约四分之一连续浅色留白，用于后期添加标题，不生成文字、乱码、水印或 Logo。

## 最佳实践

### 先锁定结构，再扩展风格

如果用户需要一组系列图，先固定画幅、主体位置、构图骨架、文案安全区、光线方向和景别，再替换人物、场景或道具。不要每条提示词都重新发明构图。

### 用比例和关系描述位置

“主体位于画面右侧三分之一、占画面高度约一半”比“主体放在右边”更容易被执行。无法精确测量时可使用“约”“大面积”“偏上”等稳健表达。

### 观察和推断分开

有参考图时，明确哪些内容是图中可见的，哪些内容是根据阴影、透视或风格推测的。没有参考图时，将镜头、灯光和材质写成“建议约束”，而不是假装已经观察到。

### 给可替换项附加边界

不要只写“背景可替换”。应写成“背景可在森林、花园和室内阅读角之间替换，但保持主体轮廓分离、左上方光线方向和标题安全区不变”。

### 文字后期处理

图片生成模型对长文案、品牌名和复杂排版的稳定性有限。生成阶段优先保证文案区域干净、比例准确、对比度合适；真实文字、字号、字距和品牌规范建议在后期设计软件中完成。

### 符合年龄与安全性

涉及婴幼儿时，提示词应使用符合年龄能力的动作，并避免高处、深水、火焰、尖锐物品和危险道具。对于绘本场景，优先使用安全、柔和、可理解的环境线索。

## 适用范围与限制

本 Skill 是视觉分析与提示词编排规范，不是图像生成器本身。它可以帮助整理需求、提炼结构和生成提示词，但不能保证任何图像模型准确复现人物一致性、复杂文字或具体品牌标识。

对于模糊、遮挡严重或分辨率较低的参考图，应明确标注不确定性。对于需要严格品牌还原、精确包装文字、法律声明或印刷成品的任务，应结合品牌规范、设计软件和人工审核流程。
